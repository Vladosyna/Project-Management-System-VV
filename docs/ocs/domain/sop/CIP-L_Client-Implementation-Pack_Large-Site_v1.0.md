**1. How Implementation Runs**

| **Step**                         | **You**                                                                                    | **VionVision**                                                          | **Timing**                        |
|----------------------------------|--------------------------------------------------------------------------------------------|-------------------------------------------------------------------------|-----------------------------------|
| **1 Kick-off and information**   | Fill the Site Information Card (Section 3); name your project owner and IT / network owner | Review the card; agree scope, KPIs and the accuracy verification method | Before the site survey            |
| **2 Site survey**                | Grant access; facility manager and IT available                                            | Joint survey: entrances, ceilings, racks, network, power                | 1–2 days per site                 |
| **3 Design and network plan**    | Confirm sensor positions and the network approach                                          | Point design and network plan (cabling, PoE, VLAN / Wi-Fi)              | Agreed in the implementation plan |
| **4 Order, delivery, storage**   | Issue the PO; provide on-site storage                                                      | Ship devices; plan the installation phases                              | Europe: 2+ weeks for delivery     |
| **5 Installation**               | Keep working windows and access open; network changes done as planned                      | Install in phases, daily progress to your project owner                 | Per implementation plan           |
| **6 Commissioning and accuracy** | Witness the accuracy verification                                                          | Configure, calibrate, verify accuracy by the agreed method              | After installation of each phase  |
| **7 Acceptance**                 | Review the handover documents; sign the Acceptance Certificate                             | Issue the handover documents (Section 5)                                | After accuracy verification       |
| **8 Operation and support**      | Report issues to your PM or support contact                                                | Warranty support, maintenance, platform updates                         | Contract term                     |

| **Before**                       | **Must be ready**                                                                                                                                                                                                      |

**6. If Conditions Are Not Met**

| **Situation**                     | **What it looks like**                                | **What happens**                                                                                                           |
|-----------------------------------|-------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------|
| **Network not as planned**        | VLAN, PoE or ports not ready on the installation day. | Installation continues where possible; affected points are scheduled for the next window once your IT confirms the change. |
| **No access to switches**         | Switches owned by a third party, credentials unknown. | Escalated to your IT / network owner the same day. We do not work on network equipment without written authorisation.      |
| **Stores closed or inaccessible** | Units closed, not yet open, or keys unavailable.      | Recorded per store; installed later or devices left on site, as you decide.                                                |
| **Working window lost**           | Late access, security not informed, mall event.       | Rescheduled to the next window. Repeated lost windows are raised with your project owner.                                  |
| **Firewall ports closed**         | Devices installed but cannot reach the platform.      | Configuration completed; data flow and commissioning resume once ports are open.                                           |

Where a phase cannot go ahead because conditions confirmed in Section 4 were not met, the additional effort may be chargeable under your contract.
